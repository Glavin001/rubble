# Physics engine benchmark

Machine: **Apple M3 Max**, 16 logical cores, macos 14.4, 128 GB
Results: `/Users/glavin/Development/rubble/.claude/worktrees/perf-three-avbd-parity/bench/results/p0-final`

Protocol: identical scene files for every engine (three-avbd's builders, Y-up), same lead-in, 2 rounds × 5 batches × 10 timed steps; **wall** = min over rounds of the median batch (ms per step, submission to GPU completion); **sync** = per-step latency p50 with a drain after every step. Quality is judged from pose dumps by one engine-neutral judge; a run's time only counts when it **passes** the scene's gates. See bench/README.md.

## Headlines: fastest passing configuration per comparison group (wall ms/step)

Only runs that pass every quality gate count; `fail` = no configuration of that engine passed, `—` = not run.
