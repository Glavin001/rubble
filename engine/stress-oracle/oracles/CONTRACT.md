# Oracle contract

Every external oracle is a separate process driven by Python scripts in
`oracles/<tool>/`. An oracle never links into the reference solver; the only
interface is two JSON formats.

## Input: `stress-scene/1`

Generated by `stress-ref gen-scenes scenes/` (the Rust catalogue in
`crates/stress-ref/src/builders.rs` is the single source; `scenes/` is not
committed). `stress-ref with-seed <scene> <seed> <out>` re-derives a scene for
another Weibull seed. Authoritative schema: `crates/stress-ref/src/scene.rs`.

- SI units, z up, quaternions `[w, x, y, z]`, default gravity `[0, 0, -9.81]`.
- `materials{name: {density, youngs_modulus, poisson_ratio, tensile_strength,
  compressive_strength, cohesion, friction, shear_cap, fracture_energy{tension,
  shear, compression}, kind: brittle|ductile, weibull_modulus, dif, static_fatigue,
  damping_ratio}}`.
- `bodies[]`: `{name, position, orientation, linear_velocity, angular_velocity,
  chunks[], bonds[]}`. Chunk and bond geometry is in the body frame.
  - chunk: `{center, half_extents, orientation, material, support:
    none|fixed|pinned, groups[], level, parent}`. Chunks are boxes. A `fixed`
    chunk has all 6 DOFs held (it is a support, e.g. a foundation course).
  - bond: `{a, b, centroid, normal (a->b), tangent, area, width[2], material,
    rebar, buckling_length, level, derived{length, i_t1, i_t2,
    torsion_constant, section_modulus_t1/t2, kn, ks, kb_t1, kb_t2, kt,
    weibull}}`. A bond is the bonded interface (patch) between two touching
    chunks. Its strength is the bond material's strengths times
    `derived.weibull`. Chunks with no bond between them are NOT connected.
- `impactors[]`: rigid `{name, shape{type: sphere(radius)|box(half_extents)},
  mass, position, orientation, velocity, angular_velocity, material, crush}`.
- `ground`: optional plane `z = height`.
- `loads[]`: `point_force{body, chunk, direction, magnitude: TimeFunction,
  point}`, `pressure{body, chunks: selector, face_normal, pressure:
  TimeFunction}` (on exposed chunk faces whose outward normal equals
  `face_normal`; positive pushes into the face), `blast{position, tnt_mass, time}`.
- `TimeFunction`: `constant{value}`, `ramp{t0,t1,value}`,
  `half_sine{start,duration,peak}`, `friedlander{arrival,peak,duration,decay}`
  (`peak (1-s) exp(-decay s)`, `s=(t-arrival)/duration`), `table{points}`.
- `events[]`: `remove_chunks{time, duration, body, chunks}` = alternate-path
  removal: at `time` the removed chunks' interface forces on the rest are
  replaced by equal external forces that ramp linearly to zero over `duration`
  (0 = sudden); `remove_supports{...}` likewise for support reactions.
- `sim{duration, frame_dt, stiffness_scale, seed, solve_mode,
  gravity_prestress, contact_restitution, contact_friction, features, ...}`.
  `gravity_prestress: true` means the structure starts in static equilibrium
  under gravity and the t=0 loads (no dynamic shock). `features{...}` are the
  reference solver's model switches (all on by default); an exporter honours the
  ones its tool can represent (e.g. `weibull: false` = every bond at mean
  strength) and records the rest in its notes.
- `probes[]` (`type` + fields): `chunk_displacement{body, chunk, axis}`,
  `chunk_velocity{...}`, `section_force{body, point, normal, region,
  component}` (internal force across the plane through `point` with `normal`,
  restricted to interfaces whose centroid is in `region`, acting on the
  `+normal` side; component `normal` = tension positive, `force: axis`,
  `moment: axis` about `point`), `reaction{body, chunks, axis}` (sum of support
  reactions on the selected chunks = force the support exerts on the
  structure), `impactor_velocity{impactor, axis}`, `impactor_position`.
- `metrics[]`: computed by `crates/stress-ref/src/metrics.rs` from
  observations; `oracles[]` names which oracles a metric is compared against,
  `tolerance` applies to the analytic `expected` value and `oracle_tolerance`
  (if given) to oracles. With several oracles the gate is their spread widened
  by the tolerance (`metrics::ensemble`); single-oracle rows are informational.
- `oracle{<tool>: {...}}`: free-form per-tool hints.

## Output: `stress-observation/1`

Write `golden/<scene>/<tool>.json` (seed 0) and `<tool>_seed<N>.json` for
other seeds. Schema: `crates/stress-ref/src/observation.rs`.

```json
{
  "format": "stress-observation/1", "scene": "<scene name>", "solver": "<tool>",
  "solver_version": "<exact version/build>", "seed": 0, "end_time": 0.1,
  "probes": {"<probe name>": {"t": [...], "v": [...], "lo": [], "hi": []}},
  "bodies": {"<body name>": [{"detached": false, "removed": false, "fragment": 3,
                               "velocity": [vx,vy,vz], "displacement": [dx,dy,dz]}, ...]},
  "flags": {"any_bond_broken": true, "collapse": false},
  "values": {"...": 0.0},
  "notes": ["modelling choices, deviations"]
}
```

- `probes`: every probe of the scene the tool can measure, same name, same
  sign convention. Sample at least as finely as the scene's `sample_interval`
  (or `frame_dt`). `lo/hi` (min/max since the previous sample) are optional.
- `bodies[name]` has one entry per scene chunk, in scene order. `detached` =
  the chunk is no longer connected to the body's main piece (the piece holding
  the supports; for an unsupported body, the heaviest piece) at `end_time`.
  `removed` = removed by a scripted event. `velocity` = mean velocity of the
  chunk's material at `end_time`, `displacement` = mean displacement of its
  centre. Continuum oracles map elements/nodes to chunks (each chunk's box);
  a chunk counts as detached if most of its mass is detached or eroded.
- `flags.any_bond_broken`: some bonded interface (or, for a continuum, some
  material at a chunk interface) failed. `flags.collapse`: some chunk detached
  from a supported body.
- Missing quantities are omitted, never faked; explain in `notes`.

## Rules

- Pin exact versions and hashes in `oracles/<tool>/PINNED.md`; record the
  command, version, input-deck hash and the scene file's sha256 in
  `golden/<scene>/provenance_<tool>.json`.
- Generate decks only from the scene file (exporter), so both sides run the
  identical setup. Keep exporter, runner and post-processor separate
  (`export.py`, `run.py`, `observe.py`) with a single entry
  `python -I oracles/<tool>/pipeline.py <scene.json> [--seed N]`.
- Fracture is chaotic: for randomized scenes compare distributions over 20+
  seeds, not single crack patterns.
