# engine-ffi: Rubble's C ABI

`include/rubble.h` is the C ABI over `rubble::World`. It is generated by
cbindgen, and `cargo test -p engine-ffi` checks that the committed copy is
current. The build produces `librubble_ffi` as a static library and as a
dynamic library.

The ABI is version **0.x**: it stays unstable until destructibles ship (D1 in
`engine/docs/public-api.md`).

## Shape

The calls follow Box3D, with an `rb` prefix:

- `rbDefault*Def()`, `rbCreate*`, `rbDestroy*`
- `rbBody_*`, `rbShape_*`, `rbJoint_*`

Each call returns an `RbResult`. `rbGetLastError()` explains the most recent
failure on the calling thread.

| Area | Rules |
|---|---|
| Handles | `uint64_t`, where 0 is null. A stale handle returns `RB_STALE_HANDLE`. |
| Definitions | Get one from `rbDefault*Def()` and change only the fields you need. A definition made any other way returns `RB_INVALID_ARGUMENT`. |
| Stepping | `rbWorld_Step` never waits. `rbWorld_Poll` returns results: either one step at a time or folded together (`coalesce`). Pointers in an `RbFrame` stay valid until the next poll. |
| Units and axes | Set `RbWorldDef::coordinates` to `RB_COORDINATES_UNREAL` for Unreal's Z-up, left-handed centimetres. The boundary converts vectors, rotations, pseudovectors (angular velocity and torque change sign), joint angles, units and triangle winding exactly. The rules are in `src/coords.rs`. |

## Example

```c
#include "rubble.h"

RbWorldDef wd = rbDefaultWorldDef();
wd.coordinates = RB_COORDINATES_UNREAL;
wd.gravity = (RbVec3){0, 0, -981};          /* cm/s^2 */
RbWorld* world;
if (rbCreateWorld(&wd, &world) != RB_OK) { puts(rbGetLastError()); }

RbBodyDef bd = rbDefaultBodyDef();
bd.type_ = RB_DYNAMIC_BODY;
bd.transform.p = (RbVec3){0, 0, 300};
RbBodyId crate_;
rbCreateBody(world, &bd, &crate_);

RbShapeDef sd = rbDefaultShapeDef();
sd.density = 0.0005f;                        /* kg/cm^3 */
RbShapeId shape;
rbCreateBoxShape(world, crate_, &sd, (RbVec3){50, 50, 50}, (RbTransform){0}, &shape);

for (;;) {
    rbWorld_Step(world);                     /* fixed step, no waiting */
    RbFrame f;
    rbWorld_Poll(world, /*coalesce*/ true, /*wait*/ false, &f);
    for (uint32_t i = 0; i < f.move_count; ++i) {
        /* interpolate f.moves[i].previous -> f.moves[i].transform */
    }
    for (uint32_t i = 0; i < f.destruction_count; ++i) { /* breaks */ }
    for (uint32_t i = 0; i < f.vehicle_count; ++i)     { /* wheels */ }
}
rbDestroyWorld(world);
```
