Reference tracings

Drag a point to move it (any line of the chosen half).
Shift-click: add a point to the active line (inserted at the nearest segment; A held: appended at its end).
Alt-click a point: delete it.
Wheel: zoom about the cursor; right-drag or space-drag: pan; 0: fit.
Wheels: drag the centre, and the rim point to set the radius. Crop: the half's outline (dashed).
Points are stored as fractions of the image width and height.
